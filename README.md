# English Study

英語の文法と単語を、7日間コース形式で学ぶ個人向け学習アプリ。

## 目的

Duolingo のような大規模サービスではなく、自分が毎日迷わず進められる英語学習環境を作る。

- レベル別・シーン別の1週間コースを選ぶ
- 文法と単語を組み合わせて、会話で使う英文を頭の中で作れるようにする
- 例文や単語をブラウザの読み上げ機能で確認する
- Supabase Auth でログインし、教材データと学習進捗をSupabaseに保存する
- PWA としてスマホ/PCから開きやすくする

## 初期方針

AIによる添削や会話機能は初期スコープに含めない。まずは完全無料で動く構成を優先する。

- コンテンツ: Supabase Postgres
- 認証/進捗保存: Supabase Auth / Postgres
- 読み上げ: Web Speech API
- オフライン対応: PWA
- AI: なし
