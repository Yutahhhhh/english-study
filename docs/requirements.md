# English Study 要件定義

## 1. 背景

英語学習では、文法知識と単語知識を別々に覚えるだけでは会話に使いにくい。自分専用の学習アプリとして、文法と単語を組み合わせ、短い英文を素早く作る練習を継続できる環境を作る。

## 2. ゴール

- レベル別・シーン別の1週間コースを一覧から選べる
- 各コースで文法、単語、例文、練習問題を日ごとに学べる
- コース、文法、単語、例文、問題をSupabaseのデータとして管理できる
- 単語帳と文法帳で学習済み項目を見返せる
- 例文や単語を英語音声で読み上げられる
- ログインして学習進捗を保存できる
- PWAとしてスマホのホーム画面から使える
- 無料で運用できる範囲を基本にする

## 3. 非ゴール

初期リリースでは以下を扱わない。

- AI添削
- AI会話
- 発音採点
- 複数ユーザー向けの管理画面
- 教材販売や課金
- 講師によるレビュー
- 高度なSNS機能

## 4. 想定ユーザー

利用者は自分のみ。複数人利用を前提にしたロール管理や個別カスタマイズは不要。ただし Supabase Auth を使い、進捗データはログインユーザーに紐づける。

## 5. 学習体験

### 5.1 コース一覧

ユーザーはSupabaseに登録されたコース一覧から、レベルやシーンでコースを選ぶ。

表示項目:

- コース名
- レベル
- シーン
- 日数
- 学習中/完了状態
- 最終学習日

想定レベル:

- Beginner
- Elementary
- Intermediate

想定シーン:

- Daily Conversation
- Travel
- Work
- Restaurant
- Shopping
- Self Introduction

### 5.2 7日間コース

1コースは基本的に7日構成にする。

各Dayの内容:

- 今日の文法
- 今日の単語
- 例文
- 日本語から英文を作る練習
- 簡単な選択/穴埋め問題
- 完了ボタン

### 5.3 単語帳

単語帳では、コースに登場した単語を一覧で確認できる。

表示項目:

- 英単語
- 日本語訳
- 品詞
- 例文
- 読み上げボタン
- ステータス

ステータス:

- new
- learning
- learned

### 5.4 文法帳

文法帳では、コースに登場した文法項目を一覧で確認できる。

表示項目:

- 文法名
- 短い説明
- 型
- 例文
- 読み上げボタン
- ステータス

ステータス:

- new
- learning
- learned

### 5.5 読み上げ

英語の単語と例文には読み上げボタンを付ける。実装はブラウザ標準の Web Speech API を使う。

要件:

- 英単語を読み上げる
- 例文を読み上げる
- 速度を通常/ゆっくりから選べる
- 読み上げ不可のブラウザではボタンを無効化する

### 5.6 進捗管理

Supabase に以下を保存する。

- コースごとの開始/完了状態
- Dayごとの完了状態
- 単語ごとの学習ステータス
- 文法ごとの学習ステータス
- 最終学習日

### 5.7 教材データ管理

Supabase に以下の教材データを保存する。

- コース
- コース内のDay構成
- 文法項目
- 単語項目
- 例文
- 練習問題
- Dayと文法/単語/例文/問題の紐づけ

教材編集用の管理画面はMVPでは作らない。初期データはSQL seedやSupabase Studioから投入する。

## 6. PWA要件

- Web App Manifest を用意する
- ホーム画面追加に対応する
- アプリアイコンを用意する
- 基本画面をキャッシュする
- 一度開いたコースコンテンツはオフラインでも参照できることを目指す
- 進捗の書き込みはオンライン時に Supabase へ保存する

初期実装では、完全なオフライン同期よりも「起動しやすさ」と「教材参照の継続性」を優先する。

## 7. Supabase要件

### 7.1 Auth

- メール/パスワードログインを使う
- 自分のアカウントのみ利用する想定
- 未ログイン時はログイン画面へ誘導する

### 7.2 Database

教材コンテンツとユーザー進捗の両方をSupabase Postgresに保存する。

保存対象:

- コース
- Day
- 文法
- 単語
- 例文
- 練習問題
- 教材間の紐づけ
- コース進捗
- Day進捗
- 単語ステータス
- 文法ステータス

### 7.3 Security

- Row Level Security を有効にする
- 進捗テーブルは `auth.uid()` と `user_id` が一致するデータだけ読み書きできるようにする
- 教材テーブルはログインユーザーが読み取り可能にする
- 教材テーブルへの書き込みはクライアントから行わない
- Supabase service role key はクライアントに置かない

## 8. 技術要件

想定スタック:

- React
- TypeScript
- Vite
- Supabase JavaScript Client
- PWA
- Web Speech API

スタイリングは実装時に選定する。既存の学習プロジェクトに合わせる場合は Tailwind CSS を優先候補にする。

## 9. MVPスコープ

MVPで作るもの:

- ログイン画面
- コース一覧
- コース詳細
- Day学習画面
- 単語帳
- 文法帳
- Supabaseからの教材データ取得
- 読み上げボタン
- 進捗保存
- PWA対応

MVPで作らないもの:

- AI機能
- 発音録音
- スコアランキング
- 管理画面
- 教材編集UI

## 10. 成功条件

- スマホからホーム画面に追加して起動できる
- ログイン後、Supabase上のコースを選んでDay学習を進められる
- 完了状態がSupabaseに保存され、別端末でも復元できる
- 単語と例文を読み上げられる
- 7日間のコースを迷わず進められる
